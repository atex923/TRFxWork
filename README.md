# 臺鐵監造紀錄小本 / TR_FxWork

版本：V0.1.d

## 執行方式

Windows 可直接執行：

```bat
python TR_FxWork.py
```

或雙擊：

```text
TR_FxWork.pyw
```

## 目前功能

- 多工程資料管理
- 開啟時自動載入最後編輯工程
- 關閉前自動儲存，編輯中也會定時自動儲存
- SQLite 本機資料庫：`TR_FxWork.db`
- 第一分頁：工程基本資料
- 第二分頁：假期表
- 第三分頁：晴雨表
- 第四分頁：鐵路疏運表
- 第五分頁：週曆總表
- 第六分頁：發包工程費計價
- 第七分頁：發包以外計價
- 第八分頁：管理費計價
- 第九分頁：工程執行紀錄表
- 第十分頁：執行狀態
- 第十一分頁：設定
- 上半部顯示：
  - 開工時間
  - 預定完工時間
  - 修正後預訂完工時間
  - 已經過施工日數
  - 到今天日期是第幾工作日
  - 發包總核銷金額
  - 發包以外核銷總金額
  - 管理費總核銷金額
  - 工程執行狀態
- 上半部新增編輯密碼輸入與解鎖按鈕
- 每個工程可獨立設定密碼；未設定密碼時不鎖定編輯
- 密碼使用 SHA256，公鑰/salt 為 `1981`，雜湊值儲存在工程資料內
- 資料庫打包備份
- 匯入備份資料
- 刪除單一工程資料

## 備份規則

備份功能會將目前 `TR_FxWork.db` 打包成 ZIP。

檔名格式：

```text
自訂檔名_YYYYMMDDHHMMSS.zip
```

例如：

```text
TR_FxWork_備份_20260605173025.zip
```

## 匯入規則

匯入 ZIP 或 DB 時，若遇到相同工程名稱，可選擇：

- 覆蓋既有工程
- 不匯入該工程，接續下一個工程匯入
- 取消並停止匯入

## 刪除工程

刪除單一工程資料前會跳出警示確認。刪除後會移除該工程所有分頁資料。

## Codex 開發備註

此版先建立功能骨架與資料結構。後續第六～第九分頁的詳細欄位、計算方式、報表輸出，再依需求逐步補齊。

## 密碼規則

- 密碼至少 3 字元。
- 未設定密碼的工程不鎖定編輯。
- 已設定密碼的工程，開啟或切換工程後會鎖定編輯。
- 必須在上半部「編輯密碼」輸入正確密碼並按「解鎖」後，才能修改工程資料或變更密碼。
- 修改密碼位置：第十一分頁「設定」。
